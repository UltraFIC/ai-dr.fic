# 005-SDK-GIT-WORKFLOW — Git Workflows & GitHub Automation

## Objetivo

Definir flujos de trabajo git, branching strategy y automatización GitHub para el desarrollo del SDK Diana y proyectos que lo consumen.

## Knowledge docs

## Criterios de exito

- Branch strategy consistente con SDD (feature branches por iniciativa).

- GitHub Actions para CI/CD del SDK.
- Gestión de versiones semver con CHANGELOG.md.
