# 014-SDK-REQUIREMENTS-ENG — Requirements Engineering & Spec Writing

## Objetivo

Dotar al agente `diana.specify` de patrones profesionales para ingeniería de requisitos, redacción de especificaciones canónicas y validación de cobertura.

## Knowledge docs

- local/domains/001-requirements-engineering.md
- local/methodology/001-sdd-lifecycle.md
- local/governance/001-constitution-design-patterns.md
- local/glossaries/001-diana-terms.md

## Criterios de exito

- Spec canónica con RF, RNF, restricciones y supuestos.
- Trazabilidad directa constitución/UCC → requisitos.
- Validación cruzada con spec operativa existente.
- Detección de gaps y ambigüedades.
- Estructura consistente con plantilla canónica.

## Fallback

Si falta esta skill, generar spec con plantilla mínima sin validación de trazabilidad. Reportar gap 014-SDK-REQUIREMENTS-ENG.
