# Testing & QA for SDK Projects

## Objetivo

Establecer prácticas de testing, validación y aseguramiento de calidad para el core SDK Diana y los proyectos generados.

## Criterios de exito

- Tests unitarios para lógica core del CLI.
- Validación de estructura generada en proyectos destino.
- Quality gates automatizados en CI.
- Pruebas de integración con templates y assets.

## Fallback

Si falta esta skill, realizar validación manual de estructuras generadas. Reportar gap 'test-qa'.
