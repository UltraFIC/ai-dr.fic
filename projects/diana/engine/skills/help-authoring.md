# Help Systems & Documentation Authoring

## Objetivo

Dotar al agente `diana.help` de patrones profesionales para autoría de documentación de ayuda, tutoriales interactivos y referencia de comandos.

## Criterios de exito

- Ayuda con sintaxis de comandos lista para copiar/pegar.
- Flujo SDD completo con orden recomendado por topología.
- Tutorial rápido por escenarios (nuevo proyecto, evolución, bugfix).
- Ejemplos concretos con argumentos reales.
- Diferenciación entre impacto global vs slice de equipo.

## Fallback

Si falta esta skill, responder con ayuda genérica sin ejemplos. Reportar gap 'help-authoring'.
