# Security Baseline for SDD Projects

## Objetivo

Definir criterios de seguridad mínimos que toda especificación, plan y conjunto de tareas Diana debe considerar.

## Criterios de exito

- Specs incluyen requisitos de seguridad explícitos.
- Plans consideran threat modeling y controles.
- Tasks incluyen verificación de seguridad.
- Principio de mínimo privilegio y defensa en profundidad considerados.

## Fallback

Si falta esta skill, incluir solo criterios de seguridad genéricos. Reportar gap 'security-baseline'.
