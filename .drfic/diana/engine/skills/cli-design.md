# CLI Design & Development Patterns

## Objetivo

Establecer convenciones para el diseño, implementación y evolución del CLI de Diana, asegurando consistencia, usabilidad y mantenibilidad.

## Criterios de exito

- CLI con interfaz consistente (argumentos, flags, output).
- Mensajes de error accionables y en español técnico.
- Separación clara entre lógica CLI y lógica de dominio.
- Soporte para modo dry-run y validación previa.

## Fallback

Si falta esta skill, mantener CLI mínimo funcional sin validación avanzada. Reportar gap 'cli-design'.
