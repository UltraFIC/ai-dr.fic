## Titulo
Demo PWA de Diana

## Contexto
Proyecto demo (dogfooding) para validar el flujo completo de DIANA SDK de punta a punta: desde `/diana.context` hasta `/diana.tasks`, usando la nueva estructura (`changes/`, `tickets/`, `.drfic/knowledge/`, `.drfic/skills-dev/`) recien reestructurada. El codigo real vivira en `projects/diana/demos/pwa/` (PWA simple, React + Vite), fuera de este arbol de gobernanza.

## Alcance
- Definir alcance funcional en el primer change de este proyecto

## Impacto Esperado
- Validar que las 15 acciones Diana (incluyendo `/diana.context` e `/diana.install-skill`, nuevas) funcionan correctamente sobre un caso real antes de usarlas en proyectos reales
- Servir de referencia/ejemplo vivo para futuros proyectos construidos con Diana

## Riesgos
- Ninguno critico: es un proyecto demo aislado, sin impacto en producto real
